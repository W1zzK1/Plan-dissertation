# 08. Развертывание

## Целевая среда MVP

MVP можно развернуть в контейнерной среде: один или несколько экземпляров Backend API, один или несколько worker-процессов, PostgreSQL, RabbitMQ и наблюдаемость. Для учебного прототипа допустим запуск через Docker Compose; для пилота - Kubernetes или управляемая контейнерная платформа.

## Диаграмма развертывания

```mermaid
C4Deployment
    title Развертывание MVP ИС Экспресс-Л
    Deployment_Node(userDevices, "Устройства пользователей", "Браузер, мобильное приложение, бот") {
        Container(client, "Клиентский канал", "Web / mobile / bot", "Создание заявок и отслеживание")
    }

    Deployment_Node(operatorDevices, "Рабочие места операторов", "Браузер") {
        Container(operatorUi, "Панель оператора", "Web", "Приемка, логистика, поддержка")
    }

    Deployment_Node(runtime, "Серверная среда", "Container runtime") {
        Container(api, "Backend API", "Go или другой backend", "HTTP API и доменные команды")
        Container(worker, "Worker", "Фоновый процесс", "Интеграции, повторы, уведомления")
    }

    Deployment_Node(dataLayer, "Слой данных", "Stateful services") {
        ContainerDb(db, "PostgreSQL", "DB", "Источник истины")
        Container(queue, "RabbitMQ", "Message broker", "Очередь заданий")
        ContainerDb(files, "Object storage", "S3-compatible", "Акты и вложения расследований")
    }

    Deployment_Node(external, "Внешние платформы", "Partner systems") {
        System_Ext(trainSystem, "Расписание и движение поездов", "API или заглушка")
        System_Ext(lastMile, "Постаматы, ПВЗ, курьеры", "API или заглушка")
        System_Ext(notifications, "Провайдер уведомлений", "API")
    }

    Rel(client, api, "HTTPS")
    Rel(operatorUi, api, "HTTPS")
    Rel(api, db, "SQL")
    Rel(api, queue, "AMQP")
    Rel(worker, queue, "AMQP")
    Rel(worker, db, "SQL")
    Rel(worker, files, "S3 API")
    Rel(worker, trainSystem, "HTTPS")
    Rel(worker, lastMile, "HTTPS")
    Rel(worker, notifications, "HTTPS")

    UpdateLayoutConfig($c4ShapeInRow="1", $c4BoundaryInRow="4")
```

## Развертываемые процессы

| Процесс | Stateful | Масштабирование | Назначение |
|---|---|---|---|
| Backend API | Нет | Горизонтально | Принимает команды, проверяет права, читает статусы |
| Worker | Нет | Горизонтально | Обрабатывает очередь, внешние вызовы, отмену по таймауту |
| PostgreSQL | Да | Вертикально или managed HA | Источник истины |
| RabbitMQ | Да | Кластер или managed broker | Надежная доставка заданий |
| Object storage | Да | Managed или совместимое хранилище | Файлы расследований |

## Конфигурация и секреты

Секреты не хранятся в репозитории. Для MVP нужны:

- строка подключения к PostgreSQL;
- адрес и учетные данные RabbitMQ;
- ключи внешних API;
- секрет подписи webhook или внешних событий;
- ключи доступа к object storage;
- настройки TTL и retry policy.

## Окружения

| Окружение | Назначение | Отличия |
|---|---|---|
| Local | Разработка и демонстрация | Docker Compose, заглушки внешних систем |
| Test | Интеграционные и контрактные проверки | Изолированные БД и очередь, fake API партнеров |
| Pilot | Ограниченная эксплуатация | Реальные или согласованные тестовые API партнеров, наблюдаемость |

## Обновления без потери заданий

- API и worker должны завершать текущие запросы при остановке.
- Worker подтверждает сообщение RabbitMQ только после успешного сохранения результата в PostgreSQL.
- При повторной доставке сообщения domain service проверяет текущее состояние и не применяет переход повторно.
- Миграции БД выполняются до запуска новой версии приложения.
