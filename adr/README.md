# ADR

Этот каталог фиксирует архитектурные решения по курсовой работе об ИС скоростной вокзальной перевозки мелких отправлений на ВСМ.

- [0003. Хранить статусы как доменные события](0003-хранить-статусы-как-доменные-события.md)
- [0004. Подключать внешние системы через адаптеры](0004-подключать-внешние-системы-через-адаптеры.md)

## Формат

Каждый ADR содержит:

- статус решения;
- контекст;
- принятое решение;
- рассмотренные альтернативы;
- последствия;
- условия пересмотра.
